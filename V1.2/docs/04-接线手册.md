## 二、JQ8900-16P 引脚（★ 按你发的实际模块）

**2×8 = 16 脚，从左到右、从上到下：**

```
 左侧（1~8）              右侧（16~9）
 ─────────────           ─────────────
 1  VPP   一线串口控制      16 DAC    模拟音频输出
 2  BUSY  播放指示(高=在播)  15 IO1
 3  RX    UART 输入 ⚠️3.3V  14 IO2
 4  TX    UART 输出 3.3V    13 IO3
 5  GND   电源地            12 IO4
 6  DC-5V 电源 ⚠️≤5.2V      11 IO5
 7  SPK-  喇叭 -            10 IO6
 8  SPK+  喇叭 +             9 IO7
```

### 接法

| 模块脚 | 接到 | 说明 |
|---|---|---|
| **1 VPP** | **不接** | 用 UART 控制，不用一线串口 |
| **2 BUSY** | **D22** | 可选，读播放状态 |
| **3 RX** | **D16 (TX2)** | ⚠️ **必须分压**（1kΩ + 2kΩ）|
| **4 TX** | **D17 (RX2)** | 3.3V，可直连 |
| **5 GND** | GND | |
| **6 DC-5V** | **5V** | ⚠️ **绝不可接 7.4V / 11.1V** |
| **7 SPK-** | 喇叭 − | |
| **8 SPK+** | 喇叭 + | **4Ω 3W** |
| 9~15 IO1~IO7 | **悬空**（可引到排针备用）| |
| **16 DAC** | 不接 | |

### ⚠️ 三个坑

1. **RX 是 3.3V TTL** —— Arduino 的 5V TX **直接接会烧模块**，必须分压
2. **DC-5V 不可超 5.2V** —— 只能从 5V 支路供，**不能接 7.4V**
3. **喇叭线远离 I²C** —— 功放瞬态电流会串扰，走线分开 + 喇叭线双绞

### 喇叭规格

**4Ω 3W**（你已有可用的）✓
- 若换 8Ω：音量会小一半，模块仍能推
- 若换 4Ω 5W：模块推不动，会失真

## 四、接线顺序（上电前检查表）

```
□ 1. 万用表测 5V / 7.4V / 3.3V / 11.1V 对地电阻，无短路
□ 2. 电池先不接，用稳压电源限流 0.5A 试上电
□ 3. 测三路电压正常 → 断开
□ 4. 插主控，再限流上电 → 测主控能跑（LED 闪）
□ 5. 接 I²C 三件 → 扫描地址，三个都能看到
□ 6. 接舵机 → 发中位脉冲 1500µs
□ 7. 接 JQ8900 + 喇叭 → 发播放指令
□ 8. 接上位机 → 串口互发测试
□ 9. 全部接上，满载跑 5 分钟 → 测温升、电压跌落
```

## 六、★ 2026-10-05 方案定案补充（覆盖前文相关部分）

### 1. 音频模块改为 **SX-TTS-E**（不再是 JQ8900）

| 项 | 变更 |
|---|---|
| **模块** | **SX-TTS-E**（中英文语音合成，**Micro USB 接口**）|
| **接法** | **Micro USB 线直插 RDK X3 的 USB 口** |
| **板上要不要留座** | ❌ **完全不留** —— 模块自带 USB-UART + 功放 + 喇叭口，**脱离主板** |
| **喇叭** | 直接接模块的喇叭口（**确认阻抗：4Ω 或 8Ω 都能用**）|
| **原 JQ8900 的 2×8P 座** | **删除** |
| **原 D16/D17（音频串口）** | **释放**，引到备用排针 |

**理由**：要朗读**任意中文**（读显示屏），JQ8900 只能播预存音频，能力不够。软件 TTS 占 RDK X3 CPU（还要跑视觉 OCR），SX-TTS-E 把合成算力卸载出去。

### 2. I²C 上拉改 **3.3V**（不再是 5V）

```
原理：I²C 是【开漏输出】，高电平完全由外部上拉决定
     主控引脚虽然工作在 5V，但只会"拉低"，从不"推高"
     → 上拉到 3.3V，总线高电平就是 3.3V
     → 主控不会往总线灌 5V，所有 3.3V 器件都安全 ✓
```

**→ 所以 AS5600 可以直接挂同一条 I²C 总线，不需要单独的电平转换模块。**

| 挂载器件 | 电平 | 是否需转换 |
|---|---|---|
| hiwonder 电机模块 | 模块自带转换 | ❌ 不需要 |
| MPU6050 模块 | 模块自带转换 | ❌ 不需要 |
| **AS5600** | 3.3V 裸器件 | ❌ **不需要**（上拉已是 3.3V）|
| **上拉电阻** | **4.7kΩ 拉到 3.3V**（不是 5V！）| — |

### 3. 保险丝方案

| 位置 | 方案 | 额定 |
|---|---|---|
| **主回路 11.1V** | **可换式**（5×20mm 玻璃管座）| **10A 慢断** |
| 5V 支路 | 贴片慢断 | 7.5A |
| 7.4V 舵机 | 贴片慢断 | 3.5A |
| 3.3V | 贴片 | 0.5A |

> ⚠️ **必须选【慢断/延时型】** —— 上电给电容充电是大电流浪涌，快断型会误动作。
> ⚠️ **保险丝不是"调试用"的，是最后一道防线** —— 锂电池短路电流可达 50A+。

### 4. 反接保护

**肖特基 MBR1045**（10A 45V，TO-220，**加散热片**），位置在【总开关之后、分路之前】。

| 连带影响 | 处理 |
|---|---|
| 压降 0.5V | 11.1V → 10.6V（对电机/ Buck 都可接受）|
| **低压保护阈值** | **要 +0.5V**：原 3.3V/cell=9.9V → **改测 10.4V** |
| ⚠️ **SS34 绝对不能用** | SMA 封装 3A，主回路 7.7A 会烧 |

### 6. TTS 模块定版：**SX-TTS-E**（2026-10-05 确认规格）

| 项 | 值 |
|---|---|
| **核心芯片** | **XFS5152CE**（科大讯飞经典 TTS，中英文）|
| **接 RDK X3** | **Micro USB**（板载 CH340 转串口）→ 直插 X3 的 USB 口 |
| **功放** | **板载 D 类功放**，直推喇叭 |
| **⚠️ 喇叭** | **接口标 `3W 4R` → 必须用 4Ω 喇叭**（8Ω 也能响，音量小一半）|
| **⚠️ 要配置** | **通信开关 + 波特率配置**（板上跳线，第一次用要设对）|
| **⚠️ 要确认** | 模块**输入电压**是 3.3V 还是 5V |

**→ 板上依然【不留】TTS 相关电路。** 模块独立挂在 X3 的 USB 口上。

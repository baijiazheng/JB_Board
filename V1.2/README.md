# JB-board V1.2 · 阿克曼底盘背板

> **定位**：不是「Arduino 拓展板」，而是**底盘背板 / 外设接口板**。
> 主控（Mega 2560 PRO MINI）插在板上的排母里，**可插拔**；外设线束和背板永久复用。

## 与 V1.1 的根本区别

| | V1.1（`JB_Balancing_Car`）| **V1.2（本仓库）** |
|---|---|---|
| 载体 | 两轮自平衡车 | **阿克曼底盘** |
| 电机/编码器 | 直连（TB6612 + 10 个引脚）| **走 I²C**（hiwonder 四路编码电机模块，2 个引脚）|
| 控制算法 | PID 在下位机 | **上位机 RDK X3 负责，下位机只做指令→执行** |
| 音频 | 无 | **JQ8900-16P**（串口语音播报）|
| 复用性 | 单项目 | **无限复用**（换主控只换排母那块）|

## 主控

**RobotDyn Mega 2560 PRO MINI**（ATmega2560-16AU，16MHz）
- 4× UART ｜ 6× 外部中断 ｜ I²C（D20/D21）｜ 16× ADC ｜ 15× PWM ｜ 54× IO
- VIN 支持 7~12V，**但板载是线性稳压器，绝不能带整车 5V 负载**（见 `03`）

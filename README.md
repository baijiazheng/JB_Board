## 设计理念的演进

```
V1.1  「平衡车主控板」
       电机/编码器直连（TB6612 + 10 个引脚）
       PID 在下位机

V1.2  「底盘背板 / 外设接口板」
       电机/编码器走 I²C（只占 2 个引脚）
       控制算法在上位机（RDK X3 + ROS2），下位机只做指令→执行
       ★ 主控可插拔 —— 换 STM32 只换排母那一块，背板和线束不动
```

**V1.2 的长期目标**：成为**可无限复用的阿克曼底盘平台**。
底盘机械 + 背板 + 线束一次做对，以后换主控、换传感器、换任务都只动局部。

## 各版本速览

### V1.2 · 阿克曼底盘背板（进行中）
- **主控**：RobotDyn Mega 2560 PRO MINI（ATmega2560-16AU）
- **电源**：3S 11.1V → 电机直供 / 7.4V 舵机 / 5V 逻辑 / 3.3V 器件
- **外设**：hiwonder 四路编码电机模块（I²C）· 舵机 · AS5600 · MPU6050 · JQ8900-16P 语音
- **接线**：全程端子，不用杜邦线
- 📄 [`V1.2/docs/01-设计输入.md`](./V1.2/docs/01-设计输入.md) —— 从功能推导到 PCB 的完整依据

## 仓库约定

**每一版的目录结构：**

```
Vx.y/
├── README.md            # 这一版为什么这样做
├── docs/                # 设计输入、引脚分配、电源、接线手册
├── hardware/            # SCH / BOM / Gerber / 3D
└── firmware/include/    # HW_CONFIG.h —— 引脚定义的唯一来源
```

**规矩：**
1. `docs/02-引脚分配.md` 与 `firmware/include/HW_CONFIG.h` **必须同步**
2. 硬件改版**必须**在 `docs/` 记下**为什么改**
3. 原理图/BOM/Gerber 归档在 `hardware/`，**文件名带日期**
